# Rhytara — Certificate of Authenticity Dashboard

Everything for the dashboard is in the **[`dashboard master`](dashboard%20master/)** folder.

**Setting it up on a Mac:**

1. Click the green **Code** button above → **Download ZIP**, unzip it, and move
   the `certificate-main` folder somewhere permanent, such as Documents.
2. Open `certificate-main` → `dashboard master` → `scripts`, and double-click
   **`setup-mac.command`** (first time only). Write down the login token it shows.
3. Any time after that, double-click **`start.command`** in the same folder to
   open the dashboard.

Certificates are saved on that Mac, inside `dashboard master/local-storage/`.
Full instructions, including what to do if macOS blocks a script, are in
[`dashboard master/README.md`](dashboard%20master/README.md#10-setting-this-up-on-your-clients-mac).
